本质上 `radio` 组件的就是一个单选的逻辑，但很多组件库的单选按钮仅限于圆形的 `radio` 按钮。

而我们的 `radio` 组件，默认我封装为了 `TRadio` 组件是圆形的 `radio` 按钮外，也支持用户自己用 `tailwindcss` 或者 `css` 来自定义样式。

你会在创意案例中你后续会增加很多好玩的单选样式。
