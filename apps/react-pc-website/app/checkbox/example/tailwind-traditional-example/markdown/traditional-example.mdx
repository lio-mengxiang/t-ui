本质上 `checkbox` 组件的就是一个多选的逻辑，但很多组件库的多选按钮仅限于方形的 `checkbox` 按钮。

而我们的 `checkbox` 组件，默认我封装为了 `TCheckbox` 组件是方形的 `checkbox` 按钮外，也支持用户自己用 `tailwindcss` 或者 `css` 来自定义样式。

你会在创意案例中你后续会增加很多好玩的多选样式。
