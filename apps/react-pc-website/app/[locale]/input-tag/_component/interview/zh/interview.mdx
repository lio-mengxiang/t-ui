<H2 className="mt-0">为什么要学 InputTag 组件</H2>

**这个组件在日常开发用的不多，但是它确实 Select 多选功能的基础组件，也就是你想学习 Select 组件，那么 InputTag 组件就必须要先学习。**

这个组件在一些自定义的场景下也会用到。

想象这样一个场景：你需要设计一个输入控件，让用户可以：

在输入框中自由添加多个标签或选项，并支持便捷的编辑与删除；

或在复杂表单中，灵活收集如关键词、联系人、分类等多组结构化信息。

虽然传统的输入框可以处理简单文本，但在面对标签化、多值输入等实际需求时却显得力不从心。因此，当前主流的前端库普遍采用自定义 InputTag 方案，以提供更直观、更灵活的多标签输入体验。这背后涉及输入交互、状态管理、视觉反馈等多重技术挑战，欢迎加入学习。
