## 1、去掉浏览器默认样式

我们要自定义 `radio` 样式的第一步，自然是去掉浏览器默认 `radio` 样式。

<CodeBlock
  code={`import { Radio, RadioProps } from '@t-headless-ui/react';
import { cs } from '@/_utils';

export const TRadio = ({ children, className, ...rest }: RadioProps) => {
  return (
    <Radio.Root
      className={cs(
        'radio-wrapper relative',
        '[&_>input[type="radio"]]:absolute [&_>input[type="radio"]]:left-0 [&_>input[type="radio"]]:top-0 [&_>input[type="radio"]]:opacity-0, [&_>input[type="radio"]]:w-0 [&_>input[type="radio"]]:h-0',
        className,
      )}
      {...rest}
    >
      {children}
    </Radio.Root>
  );
};`}
  language="jsx"
/>

`Radio.Root` 其实就是 `<label>` 元素。

上面的逻辑非常简单，就是将 `input`元素的宽高都设置为 `0`，并将其透明度设置为 `0`，这样就隐藏了默认的 `radio` 样式。
并且我们为了 `input` 元素限制在 `Radio.Root` 元素内，所以我们将 `input` 元素的 `position` 设置为 `absolute`。

<CodeBlock
  code={`/* 父元素 */
.radio-wrapper {
    position: relative;
}
 
/* 选择直接子元素 input[type="radio"] */
.radio-wrapper > input[type="radio"] {
    position: absolute;
    left: 0;
    top: 0;
    opacity: 0;
    width: 0;
    height: 0;
}`}
  language="css"
/>

然后，我们需要为了布局方便，设置一些 `flex` 居中相关样式

<CodeBlock
  code={`import { Radio, RadioProps } from '@t-headless-ui/react';
import { cs } from '@/_utils';

export const TRadio = ({ children, className, ...rest }: RadioProps) => {
  return (
    <Radio.Root
      className={cs(
        'radio-wrapper relative flex cursor-pointer items-center text-base group',
        '[&_>input[type="radio"]]:absolute [&_>input[type="radio"]]:left-0 [&_>input[type="radio"]]:top-0 [&_>input[type="radio"]]:opacity-0, [&_>input[type="radio"]]:w-0 [&_>input[type="radio"]]:h-0',
        className,
      )}
      {...rest}
    >
      {children}
    </Radio.Root>
  );
};`}
  language="jsx"
/>

我们写出对应的 `css` 样式

<CodeBlock
  code={`/* 父元素 */
.radio-wrapper {
  position: relative;
  display: flex;
  cursor: pointer;
  align-items: center;
  font-size: 1rem; /* text-base */
}
 
/* 直接子元素 input[type="radio"] */
.radio-wrapper > input[type="radio"] {
  position: absolute;
  left: 0;
  top: 0;
  opacity: 0;
  width: 0;
  height: 0;
}`}
  language="css"
/>

## 2、结合状态

因为 `radio` 组件包含很多状态，不同的状态往往对应不同的 `ui`, 所以我们需要根据不同的状态来设置不同的样式。

我们的 `Radio.Root` 帮我们内置了一些 `css` 类名，我们可以直接使用这些类名来设置不同的状态样式。

- `[&[aria-disabled="true"]]:cursor-not-allowed [&[aria-disabled="true"]]:text-color-400`：禁用状态
- `[&[aria-readonly="true"]]:cursor-default`：只读状态

对应 `css` 样式：

<CodeBlock
  code={`/* 父元素 */
.radio-wrapper {
  position: relative;
  display: flex;
  cursor: pointer;
  align-items: center;
  font-size: 1rem; /* text-base */
}
 
/* 子 radio 隐藏并覆盖在左上 */
.radio-wrapper > input[type="radio"] {
  position: absolute;
  left: 0;
  top: 0;
  opacity: 0;
  width: 0;
  height: 0;
}
 
/* 禁用状态（aria-disabled="true"） */
.radio-wrapper[aria-disabled="true"] {
  cursor: not-allowed;
  color: var(--color-400); /* 对应 text-color-400 */
}
 
/* 只读状态（aria-readonly="true"） */
.radio-wrapper[aria-readonly="true"] {
  cursor: default;
}`}
  language="css"
/>

## 3、自定义样式

我们单独写一个组件，来实现自定义 `radio` 样式, 我们取名为 `Indicator`。

<CodeBlock
      code={`import { Radio, RadioProps } from '@t-headless-ui/react';
import { cs } from '@/_utils';
 
function Indicator() {
  const { checked, disabled, readonly } = useContext(Radio.RadioContext);

return (

<div
  className={cs(
    'radio-icon relative border border-color border-solid rounded-full w-4 h-4 transition-all duration-300 shadow-sm after:transition-all after:duration-300',
    'after:content-[""] after:absolute after:top-1/2 after:left-1/2 after:transform after:-translate-x-1/2 after:-translate-y-1/2 after:w-[7px] after:h-[7px] after:rounded-full after:bg-none',
    {
      'after:bg-color-800': checked && !disabled,
      'after:bg-color-200': checked && disabled,
      'cursor-not-allowed': disabled,
      'hover:border-color-100 group-hover:border-color-100': !disabled && !readonly,
      'cursor-default': readonly,
    },
  )}
></div>
); }`} language="jsx" />

首先说明一下：

- `useContext(Radio.RadioContext)` 用来获取 `radio` 组件的状态，比如 `checked`, `disabled`, `readonly` 等等。
- `cs` 是一个 `classnames` 库的函数，用来合并 `class` 名。

因为我们在之前说过，`Radio` 组件的本质就是切换 `checked` 状态而已，所以我们通过 `context` api 来共享这些状态。

然后 `css` 部分如下，说白了就是画了一个圆形的 `div`，并根据 `checked` 状态来设置不同的样式。当然注意 `disabled`, `readonly` 状态下的样式。

<CodeBlock
  code={`.radio-icon {
  position: relative;
  width: 1rem; /* w-4 */
  height: 1rem; /* h-4 */
  border: 1px solid var(--color);
  border-radius: 9999px; /* rounded-full */
  transition: all 0.3s;
  box-shadow: var(--shadow-sm);
}
 
/* 圆点（选中状态的伪元素） */
.radio-icon::after {
  content: "";
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 7px;
  height: 7px;
  border-radius: 9999px;
  background: none;
  transition: all 0.3s;
}
 
/* -------- 状态控制：checked + enabled -------- */
 
/* checked + !disabled */
.radio-icon.checked:not(.disabled)::after {
  background: var(--color-800);
}
 
/* checked + disabled */
.radio-icon.checked.disabled::after {
  background: var(--color-200);
}
 
/* -------- 禁用状态 -------- */
.radio-icon.disabled {
  cursor: not-allowed;
}
 
/* -------- 悬停状态（可点击且非只读）-------- */
.radio-icon.hoverable:hover,
.radio-icon.hoverable.group-hover {
  border-color: var(--color-100);
}
 
/* -------- 只读状态 -------- */
.radio-icon.readonly {
  cursor: default;
}`}
  language="css"
/>

## 4、小结

我们贴上完整代码：

<CodeBlock
  code={`import React, { useContext } from 'react';
import { Radio, RadioProps } from '@t-headless-ui/react';
import { cs } from '@/_utils';
 
export const TRadio = ({ children, className, ...rest }: RadioProps) => {
  return (
    <Radio.Root
      className={cs(
        'relative flex cursor-pointer items-center text-base group',
        '[&_>input[type="radio"]]:absolute [&_>input[type="radio"]]:left-0 [&_>input[type="radio"]]:top-0 [&_>input[type="radio"]]:opacity-0, [&_>input[type="radio"]]:w-0 [&_>input[type="radio"]]:h-0',
        '[&[aria-disabled="true"]]:cursor-not-allowed [&[aria-disabled="true"]]:text-color-400',
        '[&[aria-readonly="true"]]:cursor-default',
        className,
      )}
      {...rest}
    >
      <Indicator />
      <div className="ml-2">{children}</div>
    </Radio.Root>
  );
};
 
function Indicator() {
  const { checked, disabled, readonly } = useContext(Radio.RadioContext);
 
  return (
    <div
      className={cs(
        'relative border border-color border-solid rounded-full w-4 h-4 transition-all duration-300 shadow-sm after:transition-all after:duration-300',
        'after:content-[""] after:absolute after:top-1/2 after:left-1/2 after:transform after:-translate-x-1/2 after:-translate-y-1/2 after:w-[7px] after:h-[7px] after:rounded-full after:bg-none',
        {
          'after:bg-color-800': checked && !disabled,
          'after:bg-color-200': checked && disabled,
          'cursor-not-allowed': disabled,
          'hover:border-color-100 group-hover:border-color-100': !disabled && !readonly,
          'cursor-default': readonly,
        },
      )}
    ></div>
  );
}`}
  language="jsx"
/>
