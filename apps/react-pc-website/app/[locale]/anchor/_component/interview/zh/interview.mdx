<H2 className="mt-0">为什么要学 Anchor 组件</H2>

**Anchor 组件是前端实现页面内定位导航的关键技术，也是构建现代 Web 应用的基础能力之一。**

想象这样一个场景：你需要开发一个组件，让任意一个 DOM 元素能够：

- 在用户交互时，自动滚动到页面或某个滚动容器的指定位置；

- 或在 URL 跳转后，精准定位到页面或滚动容器的目标区域。

虽然浏览器原生支持锚点跳转，但功能较为局限，因此当前主流的前端库普遍采用自定义 `Anchor` 方案来实现更灵活、更强大的定位功能。这背后涉及多个技术挑战，欢迎加入学习。
