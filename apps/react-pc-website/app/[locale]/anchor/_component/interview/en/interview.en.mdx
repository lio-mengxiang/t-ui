<H2 className="mt-0">The Core Principles of the Anchor Component</H2>

**The Anchor component is a key technology for implementing in-page positioning and navigation in front-end development, and it is one of the essential capabilities for building modern web applications.**

Imagine this scenario: you need to develop a component that enables any DOM element to:

- Automatically scroll to a specific position within the page or a scrollable container upon user interaction;

- Or accurately locate the target area within the page or a scrollable container after a URL redirect.

Although browsers natively support anchor navigation, its functionality is quite limited. Therefore, mainstream front-end libraries commonly adopt custom Anchor solutions to achieve more flexible and powerful positioning features. This involves several technical challenges, detailed in the "Technical Challenges" section below.
