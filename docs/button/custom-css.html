1、抽象 Button 状态

对于 button 我们可以将一些常用的功能单独抽离成 css 变量。例如：

  • 设置不同主题色：例如 primary（主色）, success（成功状态）, error（失败状态） 等等。
  • 设置 disabled 状态的背景色，文字颜色（不同主题色还需要分别设置不同的 disabled 状态色）
  • 等等

注：如果你对主题换肤方案感兴趣，请查看组件库全局解决方案之换肤方案篇：

  • CSS 换肤方案
  • Tailwind 换肤方案
  • Next.js 换肤方案

如下，可以看到，我们定义了一些跟颜色相关的 css 变量, 放入了 .btn-primary-fill 这个类名：

1.btn-primary-fill { 2 --btn-padding: 0 14px; 3 --btn-height: 36px; 4 --btn-font-size: 14px; 5 --transition-timing-function-standard: cubic-bezier(0.34, 0.69, 0.1, 1); 6 --btn-lineHeight: 1.5715; 7 --btn-radius: 4px; 8 --btn-bg-color: #2563eb; 9 --btn-bg-disabled-color: #93c5fd; 10 --btn-text-color: #fff; 11}

2、增加 loading/hover 态

我们上面定义了正常和 disabled 状态的 css 变量，接下来 loading 状态需要的是一个 loading 图标， 图标我们直接从 @t-headless-ui/react 中获取, 对 loading 处理是传入参数 loading: true 的参数， 就会出现 loading 图标，当然你可以自定义任意 loading 图标。

需要注意，loading 状态，onClick 事件是不会触发。

接着我们增加一下 hover 状态，为什么需要 hover 态呢？好处就是当 hover 按钮时，能给对面一个反馈，知道此时正在 hover 哪个按钮，我们使用如下 css 实现：

1.btn-primary-fill { 2 /* ... */ 3 --btn-bg-hover: #4670d2; 4} 5.btn-primary-fill:not(:disabled):not(.normal-btn-loading):hover { 6 border-color: transparent; 7 color: #fff; 8 background-color: var(--btn-bg-hover); 9}

3、增加 active/focus 态

active 状态是指点击按钮且没有离开按钮时的状态，表明按钮正在被点击，我们在后续的 《创意案例》 章节会有 很多有意思的案例，比如点击按钮时，按钮会有一个波纹效果，会有彩带等等。

focus 状态是指当我们使用键盘的 tab 键选中按钮时的状态。主要是有些场景用户希望用 tab 快速选中按钮 例如在弹框组件中，往往会有确定和取消两个按钮，我们就可以使用 tab 快速选中。所以有一个 ui 上能区分是否 focus 对应按钮是很有必要的。

加这个两个状态也就是几行 css 的事，如下：

1.btn-primary-fill:not(:disabled):not(.normal-btn-loading):active { 2background-color: theme('colors.primary.active'); 3color: #fff; 4border: 1px solid transparent; 5} 6 7.btn-primary-fill:not(:disabled):focus-visible { 8outline: 2px solid theme('colors.primary.focus'); 9outline-offset: 1px; 10}

4、使用 css 增强 Button

  • 按钮尺寸：很多库会让 Button 组件支持 lg、sm 等尺寸，其实就是修改一下 height 和 padding 即可。

我们先拿按钮尺寸来举例，在这之前，我们首先要明白一个很重要的辅助函数 classNames。

简单来说 classNames 是一个帮助你动态拼接 CSS 类名的小工具，让你写样式时更简洁、更清晰。

🎯 为什么需要它？ 你可能经常会写这样的代码：

1<div className={isActive ? "btn active" : "btn"}>点击我</div>

但当你的条件变多，代码就会变得很乱，比如这样：

1<div className={isActive ? (isDisabled ? 'btn active disabled' : 'btn active') : isDisabled ? 'btn disabled' : 'btn'}>点击我</div>

😵 看起来非常难读！我们可以用 classnames 简化

1import classNames from "classnames"; 2 3<div 4className={classNames('btn', { 5 active: isActive, 6 disabled: isDisabled, 7})} 8> 9点击我 10</div> 11

这会根据 isActive 和 isDisabled 的值自动拼接类名。

比如：

  • isActive = true, isDisabled = false ➜ "btn active"

  • isActive = false, isDisabled = true ➜ "btn disabled"

  • 都为 true ➜ "btn active disabled"

classNames 还支持传入数组，比如：

1<div className={classNames('btn', ['active', 'disabled'])}>点击我</div>

这会拼接 "btn active disabled" 这个类名。

好了，我们接着之前的增加按钮尺寸的功能。 我们使用 classNames 辅助函数，动态拼接 CSS 类名，实现按钮尺寸的功能。还有，我自己实现了一个简单 classNames 辅助函数，命令为 cs。

5、增加实现 group 按钮

这个也比较好实现，其实也算是简单的 css 功能。我们可以在 Button 组件外层包裹一个 div，然后给 div 加上一个类名，例如 button-group。

  • 然后对于 button-group 第一个子元素，也就是第一个 Button 组件，我们可以给它左上角和左下角加上一个 border-radius，例如 4px。
  • 接着对于 button-group 最后一个子元素，也就是最后一个 Button 组件，我们可以给它右上角和右下角加上一个 border-radius，例如 4px。

就轻松实现 group 按钮的功能了。

css 大致如下（以下代码还处理了一些边界情况，例如按钮重合部分，有的边框需要）

1.btn-group { 2 display: inline-flex; 3 --btn-radius: 4px; 4} 5.btn-group .normal-btn:first-child { 6 border-radius: var(--btn-radius) 0 0 var(--btn-radius); 7} 8.btn-group .btn-outline:first-child:hover { 9 border-right-color: transparent; 10} 11.btn-group .normal-btn:not(:first-child):not(:last-child):hover { 12 border-right-color: transparent; 13} 14.btn-group .normal-btn:last-child { 15 border-radius: 0 var(--btn-radius) var(--btn-radius) 0; 16} 17.btn-group .normal-btn:not(:first-child):not(:last-child) { 18 border-radius: 0; 19} 20.btn-group .normal-btn:not(:last-child) { 21 border-right: 1px solid rgba(255, 255, 255, 20%); 22}
