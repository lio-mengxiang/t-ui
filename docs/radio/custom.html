简单封装 Radio 组件

孟祥_成都 🔥前端技术专家，全栈开发工程师

注：以下样式使用的是 tailwindcss 类名。你可以完全使用 css 类名来代替，我们也会写对应的 css 样式。样式都很简单。

1、去掉浏览器默认样式

我们要自定义 radio 样式的第一步，自然是去掉浏览器默认 radio 样式。

1import { Radio, RadioProps } from '@t-headless-ui/react'; 2import { cs } from '@/_utils'; 3 4export const TRadio = ({ children, className, ...rest }: RadioProps) => { 5return ( 6 <Radio.Root 7 className={cs( 8 'radio-wrapper relative', 9 '[&_>input[type="radio"]]:absolute [&_>input[type="radio"]]:left-0 [&_>input[type="radio"]]:top-0 [&_>input[type="radio"]]:opacity-0, [&_>input[type="radio"]]:w-0 [&_>input[type="radio"]]:h-0', 10 className, 11 )} 12 {...rest} 13 > 14 {children} 15 </Radio.Root> 16); 17};

Radio.Root 其实就是 <label> 元素。

上面的逻辑非常简单，就是将 input元素的宽高都设置为 0，并将其透明度设置为 0，这样就隐藏了默认的 radio 样式。 并且我们为了 input 元素限制在 Radio.Root 元素内，所以我们将 input 元素的 position 设置为 absolute。

1/* 父元素 */ 2.radio-wrapper { 3 position: relative; 4} 5 6/* 选择直接子元素 input[type="radio"] */ 7.radio-wrapper > input[type="radio"] { 8 position: absolute; 9 left: 0; 10 top: 0; 11 opacity: 0; 12 width: 0; 13 height: 0; 14}

然后，我们需要为了布局方便，设置一些 flex 居中相关样式

1import { Radio, RadioProps } from '@t-headless-ui/react'; 2import { cs } from '@/_utils'; 3 4export const TRadio = ({ children, className, ...rest }: RadioProps) => { 5return ( 6 <Radio.Root 7 className={cs( 8 'radio-wrapper relative flex cursor-pointer items-center text-base group', 9 '[&_>input[type="radio"]]:absolute [&_>input[type="radio"]]:left-0 [&_>input[type="radio"]]:top-0 [&_>input[type="radio"]]:opacity-0, [&_>input[type="radio"]]:w-0 [&_>input[type="radio"]]:h-0', 10 className, 11 )} 12 {...rest} 13 > 14 {children} 15 </Radio.Root> 16); 17};

我们写出对应的 css 样式

1/* 父元素 */ 2.radio-wrapper { 3position: relative; 4display: flex; 5cursor: pointer; 6align-items: center; 7font-size: 1rem; /* text-base */ 8} 9 10/* 直接子元素 input[type="radio"] */ 11.radio-wrapper > input[type="radio"] { 12position: absolute; 13left: 0; 14top: 0; 15opacity: 0; 16width: 0; 17height: 0; 18}

2、结合状态

因为 radio 组件包含很多状态，不同的状态往往对应不同的 ui, 所以我们需要根据不同的状态来设置不同的样式。

我们的 Radio.Root 帮我们内置了一些 css 类名，我们可以直接使用这些类名来设置不同的状态样式。

  • [&[aria-disabled="true"]]:cursor-not-allowed [&[aria-disabled="true"]]:text-color-400：禁用状态
  • [&[aria-readonly="true"]]:cursor-default：只读状态

对应 css 样式：

1/* 父元素 */ 2.radio-wrapper { 3position: relative; 4display: flex; 5cursor: pointer; 6align-items: center; 7font-size: 1rem; /* text-base */ 8} 9 10/* 子 radio 隐藏并覆盖在左上 */ 11.radio-wrapper > input[type="radio"] { 12position: absolute; 13left: 0; 14top: 0; 15opacity: 0; 16width: 0; 17height: 0; 18} 19 20/* 禁用状态（aria-disabled="true"） */ 21.radio-wrapper[aria-disabled="true"] { 22cursor: not-allowed; 23color: var(--color-400); /* 对应 text-color-400 */ 24} 25 26/* 只读状态（aria-readonly="true"） */ 27.radio-wrapper[aria-readonly="true"] { 28cursor: default; 29}

3、自定义样式

我们单独写一个组件，来实现自定义 radio 样式, 我们取名为 Indicator。

1import { Radio, RadioProps } from '@t-headless-ui/react'; 2import { cs } from '@/_utils'; 3 4function Indicator() { 5const { checked, disabled, readonly } = useContext(Radio.RadioContext); 6 7return ( 8 9<div 10className={cs( 11 'radio-icon relative border border-color border-solid rounded-full w-4 h-4 transition-all duration-300 shadow-sm after:transition-all after:duration-300', 12 'after:content-[""] after:absolute after:top-1/2 after:left-1/2 after:transform after:-translate-x-1/2 after:-translate-y-1/2 after:w-[7px] after:h-[7px] after:rounded-full after:bg-none', 13 { 14 'after:bg-color-800': checked && !disabled, 15 'after:bg-color-200': checked && disabled, 16 'cursor-not-allowed': disabled, 17 'hover:border-color-100 group-hover:border-color-100': !disabled && !readonly, 18 'cursor-default': readonly, 19 }, 20)} 21></div> 22); }

首先说明一下：

  • useContext(Radio.RadioContext) 用来获取 radio 组件的状态，比如 checked, disabled, readonly 等等。
  • cs 是一个 classnames 库的函数，用来合并 class 名。

因为我们在之前说过，Radio 组件的本质就是切换 checked 状态而已，所以我们通过 context api 来共享这些状态。

然后 css 部分如下，说白了就是画了一个圆形的 div，并根据 checked 状态来设置不同的样式。当然注意 disabled, readonly 状态下的样式。

1.radio-icon { 2position: relative; 3width: 1rem; /* w-4 */ 4height: 1rem; /* h-4 */ 5border: 1px solid var(--color); 6border-radius: 9999px; /* rounded-full */ 7transition: all 0.3s; 8box-shadow: var(--shadow-sm); 9} 10 11/* 圆点（选中状态的伪元素） */ 12.radio-icon::after { 13content: ""; 14position: absolute; 15top: 50%; 16left: 50%; 17transform: translate(-50%, -50%); 18width: 7px; 19height: 7px; 20border-radius: 9999px; 21background: none; 22transition: all 0.3s; 23} 24 25/* -------- 状态控制：checked + enabled -------- */ 26 27/* checked + !disabled */ 28.radio-icon.checked:not(.disabled)::after { 29background: var(--color-800); 30} 31 32/* checked + disabled */ 33.radio-icon.checked.disabled::after { 34background: var(--color-200); 35} 36 37/* -------- 禁用状态 -------- */ 38.radio-icon.disabled { 39cursor: not-allowed; 40} 41 42/* -------- 悬停状态（可点击且非只读）-------- */ 43.radio-icon.hoverable:hover, 44.radio-icon.hoverable.group-hover { 45border-color: var(--color-100); 46} 47 48/* -------- 只读状态 -------- */ 49.radio-icon.readonly { 50cursor: default; 51}

4、小结

我们贴上完整代码：
